**I asked my smart speaker to play something relaxing, and it read out my credit card balance.**

You ask for calm; the speaker answers with the one number guaranteed to
destroy it. One setup, one twist, no explanation needed — and it stays funny
the second time, because everyone has heard that number read back to them.
